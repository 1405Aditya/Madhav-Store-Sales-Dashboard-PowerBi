# 🏪 Madhav Store Sales Dashboard (Power BI)

## 📌 Overview

This project presents a Power BI dashboard analyzing retail store sales data, focusing on product performance and overall business trends.

## 🎯 Objectives

* Monitor store-level sales performance
* Identify top-selling products
* Analyze monthly sales trends
* Support data-driven decision-making

## 📊 Key Insights

* Sales are driven by a few high-performing products
* Monthly trends indicate fluctuations in performance
* Product-level analysis helps identify key revenue drivers

## 🛠 Tools Used

* Power BI
* DAX
* Data Visualization
